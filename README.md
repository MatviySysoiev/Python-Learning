## 🚀 Getting Started

### Prerequisites
* Python 3.x installed on your system.

### Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/MatviySysoiev/Python-Learning
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # On Windows:
   .venv\Scripts\activate
   # On macOS/Linux:
   source .venv/bin/activate
   ```

## 💡 Usage
You can run any individual script using Python from your terminal:
```bash
python learning/Beginner/lists.py
```
